The heartbeat monitor compares agent last_heartbeat against now to determine if an agent is offline. This is the most likely place for a naive/aware TypeError to surface at runtime. Find the comparison:
```python
now = datetime.utcnow()

```
Fix:
```python
now = datetime.now(timezone.utc)
threshold = now - timedelta(seconds=...)
```

**For app/services/hatchet_service.py (~13 occurrences):**

Several of these involve `.isoformat()` calls on the result, e.g.:
```python
"executed_at": datetime.utcnow().isoformat()
```
Fix to:
```python
"executed_at": datetime.now(timezone.utc).isoformat()
```
Some involve `.timestamp()` calls:
```python
"deadline_at": datetime.utcnow().timestamp() + step.timeout_seconds
```
Fix to:
```python
"deadline_at": datetime.now(timezone.utc).timestamp() + step.timeout_seconds
```
Both `.isoformat()` and `.timestamp()` work identically on aware datetimes.
