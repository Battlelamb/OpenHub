**Step 2: Remove the blocking time.sleep(1) call**

The existing code has:


**Step 3: Verify HeartbeatService has no blocking calls in start_monitoring**

Read heartbeat_service.py. If `start_monitoring` uses `asyncio.create_task()`, confirm the task is stored as an instance variable so `stop_monitoring` can cancel it. If the implementation already does this correctly, make no changes to heartbeat_service.py. If `stop_monitoring` is missing or incomplete, add:
```python
async def stop_monitoring(self) -> None:
    """Cancel the heartbeat monitoring background task."""
    if hasattr(self, '_monitor_task') and self._monitor_task:
        self._monitor_task.cancel()
        try:
            await self._monitor_task
        except asyncio.CancelledError:
            pass
        self._monitor_task = None
    logger.info("heartbeat_monitor_stopped")
```
