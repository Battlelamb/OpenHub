## Notes

1. **Health endpoint**: The main `/v1/health` endpoint requires `RequestIdDep` which reads from headers. Test uses `/v1/health/simple` instead which has no dependencies.

2. **In-memory database**: Tests use `:memory:` SQLite DB for isolation and speed.

3. **Environment variables**: Test fixtures set required env vars before app import to bypass pydantic-settings validation. These will be replaced with real required fields in Plan 01 (HARD-02).
