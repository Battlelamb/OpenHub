## Guardrails preserved

- ANP compatibility is discovery only; it does not replace ACN auth/trust.
- Agents remain private unless explicitly opted in through `labels["anp_public"] == "true"`, `metadata["anp_public"] is true`, or `metadata["public"] is true`.
- Public responses never serialize raw labels or raw metadata wholesale.
- Public responses must never expose API keys, bearer strings, admin values, tokens, secrets, IPs, hostnames, workspace paths, local paths, environment values, process IDs, or bridge command lines.
- DID values are included only when explicitly supplied; they are never synthesized.
- No release/tag/publish action is approved yet.
