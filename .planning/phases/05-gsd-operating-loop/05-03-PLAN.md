# Phase 05-03 — Stuck Work Recovery UX

## Goal
Detect stale claimed/running tasks with expired leases, surface them in the API with clear status, and add admin recovery action guarded by tests.

## Tasks (small focused slices)

- Add service method to find all stale tasks
- Unit tests for detection logic
- Commit

### 05-03-02: Recovery API Endpoint
- Add `POST /v1/tasks/{task_id}/recover` admin endpoint
- Guard with RBAC (admin role only)
- Integration tests for recovery action
- Commit

### 05-03-03: Stale Task Listing Endpoint
- Add `GET /v1/tasks/stale` endpoint
- Return stale tasks with age, original assignee, reason
- Integration tests
- Commit

### 05-03-04: Audit Trail for Recovery
- Log recovery events with actor, timestamp, reason
- Add recovery metadata to task model
- Tests for audit trail
