Add an optional `on_event` callback parameter to each service class. The callback pattern avoids circular imports (research anti-pattern guidance). The callback signature is: `async def on_event(event_type: str, data: dict, critical: bool = True) -> None`.

**For AgentService** (`app/services/agent_service.py`):

1. Add `on_event` param to `__init__`:
   ```python
   def __init__(self, database, on_event=None):
       self.db = database
       self._on_event = on_event
       ...
   ```

2. Add helper method:
   ```python
   async def _emit(self, event_type: str, data: dict, critical: bool = True):
       if self._on_event:
           try:
               await self._on_event(event_type, data, critical)
           except Exception as e:
               logger.warning("event_emit_failed", event_type=event_type, error=str(e))
   ```

3. After `register_agent` returns successfully, add:
   ```python
   # Note: register_agent is sync, so we can't await here.
   # The route handler will call the emit after the sync return.
   ```
   Instead, return the agent object and let the route handler emit. OR change approach: since services are sync but broadcasts are async, the broadcast call will happen in the route handler after the service call returns. Document this.

**REVISED APPROACH**: Since existing services are synchronous and ConnectionManager.broadcast_to_ui is async, the cleanest approach is to emit events from the route handlers, not from within the service classes. This avoids needing to make services async.

**Implementation pattern for route handlers:**

```python
# In route handler, after service call:

if cm:

        "task_id": task_id,
        "status": "queued",
        "previous_status": None,
    }, critical=True)
```

Use `getattr(..., None)` so tests that don't have ConnectionManager wired don't fail.
