Create app/services/connection_manager.py implementing the ConnectionManager class per D-09, D-10, D-12, D-13, D-14, D-15.

File structure:

1. **Imports**: asyncio, json, datetime, typing, fastapi.WebSocket, prometheus_client (Gauge, Counter), app.logging, app.config

2. **Prometheus metrics** (module-level, per D-15):
   - `WS_CONNECTIONS_ACTIVE = Gauge("openhub_ws_connections_active", "Active WebSocket connections", ["type"])` - labels: "agent", "ui"
   - `WS_EVENTS_SENT_TOTAL = Counter("openhub_ws_events_sent_total", "Total WebSocket events sent", ["event_type"])`
   - `WS_ERRORS_TOTAL = Counter("openhub_ws_errors_total", "Total WebSocket errors")`

3. **ConnectionManager class** with:

   **State:**
   - `self._agents: Dict[str, WebSocket] = {}`
   - `self._ui_clients: Dict[str, WebSocket] = {}`
   - `self._ui_expiry: Dict[str, float] = {}` (JWT expiry timestamps per client_id, for D-11)
   - `self._batch_buffer: List[dict] = []`
   - `self._batch_task: Optional[asyncio.Task] = None`
   - `self._running: bool = False`

   **Methods:**

   `async def start(self) -> None`:
   - Set self._running = True
   - Start batch loop: `self._batch_task = asyncio.create_task(self._batch_loop())`
   - Log "connection_manager_started"

   `async def stop(self) -> None`:
   - Set self._running = False
   - Cancel batch task if exists
   - Close all connections with 4003 close code
   - Log "connection_manager_stopped"

   `async def connect_agent(self, agent_id: str, ws: WebSocket) -> bool`:
   - Check limit: `len(self._agents) >= settings.max_ws_agents` -> return False
   - Log warning at 80% capacity: `len(self._agents) >= settings.max_ws_agents * 0.8`
   - Store: `self._agents[agent_id] = ws`
   - Increment gauge: `WS_CONNECTIONS_ACTIVE.labels(type="agent").inc()`
   - Return True

   `async def connect_ui(self, client_id: str, ws: WebSocket, jwt_exp: float) -> bool`:
   - Check limit: `len(self._ui_clients) >= settings.max_ws_ui` -> return False
   - Log warning at 80% capacity
   - Store: `self._ui_clients[client_id] = ws`, `self._ui_expiry[client_id] = jwt_exp`
   - Increment gauge: `WS_CONNECTIONS_ACTIVE.labels(type="ui").inc()`
   - Return True

   `async def disconnect_agent(self, agent_id: str) -> None`:
   - Pop from self._agents
   - Dec gauge if was present

   `async def disconnect_ui(self, client_id: str) -> None`:
   - Pop from self._ui_clients and self._ui_expiry
   - Dec gauge if was present

   `async def broadcast_to_ui(self, event_type: str, data: dict, critical: bool = True) -> int`:
   - If not critical: append to batch buffer `{"event_type": event_type, "data": data}` and return 0
   - If critical: iterate self._ui_clients, send_json with format `{"event": event_type, "data": data, "timestamp": datetime.now(timezone.utc).isoformat()}`
   - Catch exceptions per-client, disconnect failed clients, increment WS_ERRORS_TOTAL
   - Increment WS_EVENTS_SENT_TOTAL.labels(event_type=event_type) per successful send
   - Return count of successful sends

   `async def broadcast_to_agents(self, event_type: str, data: dict, exclude: str = None) -> int`:
   - Same pattern as broadcast_to_ui but iterates self._agents
   - Skip excluded agent_id

   `async def send_to_client(self, client_id: str, event_type: str, data: dict) -> bool`:
   - Send to specific UI client by client_id
   - Return True if sent, False if not connected

   `async def flush_batch(self) -> int`:
   - Drain self._batch_buffer, broadcast each event to UI clients
   - Return total events sent
   - This method exists for deterministic testing (D-06 test approach)

   `async def _batch_loop(self) -> None`:
   - While self._running: await asyncio.sleep(5.0), then call flush_batch()
   - Wrap in try/except asyncio.CancelledError

   `async def _check_token_expiry(self) -> None`:
   - Called from batch_loop or separately
   - For each client in self._ui_expiry, if expiry - now < 60s, send `{"event": "token_expiring", "data": {"expires_in": remaining_seconds}}`
   - If expiry < now, disconnect with close code 4001 per D-11/D-14

   **Properties:**
   - `agent_count -> int`: len(self._agents)
   - `ui_client_count -> int`: len(self._ui_clients)
   - `connected_agents -> list[str]`: list(self._agents.keys())
   - `connected_ui_clients -> list[str]`: list(self._ui_clients.keys())

Use `from ..logging import get_logger` and `from ..config import get_settings` at module top.
Call `settings = get_settings()` at module level.
