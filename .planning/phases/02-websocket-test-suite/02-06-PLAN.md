Create tests/integration/test_websocket.py using Starlette TestClient's websocket_connect.

Use SYNCHRONOUS test functions (not async) with the TestClient. This is critical per Pitfall 3 from research.

Pattern for each test:
```python
def test_ws_ui_auth_success(test_client, auth_token):
    with test_client.websocket_connect("/v1/ws/ui") as ws:
        # Send auth message
        ws.send_json({"token": auth_token})
        # Receive welcome
        data = ws.receive_json()
        assert data["event"] == "connected"
        assert "agent_id" in data
```

For auth failure tests, the server closes the connection. Starlette TestClient raises `WebSocketDisconnect` when the server sends a close frame. Wrap in try/except:
```python
from starlette.websockets import WebSocketDisconnect

def test_ws_ui_auth_invalid_token(test_client):
    with test_client.websocket_connect("/v1/ws/ui") as ws:
        ws.send_json({"token": "invalid-garbage-token"})
        try:
            ws.receive_json()
            assert False, "Should have been disconnected"
        except WebSocketDisconnect as e:
            assert e.code == 4001
```

For expired token test: create a token with negative expiry:
```python
from datetime import timedelta
from app.auth.jwt_auth import create_access_token

expired_token = create_access_token(
    subject="test-admin",

    claims={"role": "admin"}

```

For disconnect cleanup: after the `with` block exits, check `test_client.app.state.connection_manager.ui_client_count == 0`.
