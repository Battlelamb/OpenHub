Create app/api/routes_ws_ui.py with the /v1/ws/ui WebSocket endpoint per D-02, D-03, D-14.

```python
"""WebSocket endpoint for dashboard UI clients."""
import asyncio
import json
from datetime import datetime, timezone
from fastapi import APIRouter, WebSocket, WebSocketDisconnect

from ..auth.jwt_auth import verify_token
from ..logging import get_logger

logger = get_logger(__name__)
router = APIRouter(tags=["websocket"])
```

The endpoint `@router.websocket("/v1/ws/ui")` should:

1. **Accept connection** - call `await websocket.accept()` immediately (WS protocol requires accept before sending close frames in some implementations)

2. **Wait for auth message** (10s timeout per research):
   ```python
   try:
       raw = await asyncio.wait_for(websocket.receive_text(), timeout=10.0)
       msg = json.loads(raw)
   except (asyncio.TimeoutError, json.JSONDecodeError):
       await websocket.close(code=4001, reason="auth timeout or invalid format")
       return
   ```

3. **Extract and verify JWT**:
   - Get `token = msg.get("token")`
   - If no token: close with code=4001, reason="token required in first message"
   - Call `payload = verify_token(token, expected_type="access")`
   - On jwt.ExpiredSignatureError or jwt.InvalidTokenError: close with code=4001, reason="invalid or expired token"

4. **Extract client identity**: `client_id = payload["sub"]`, `jwt_exp = payload["exp"]`

5. **Register with ConnectionManager**:
   ```python
   cm = websocket.app.state.connection_manager
   if not await cm.connect_ui(client_id, websocket, jwt_exp):
       await websocket.close(code=4002, reason="connection limit reached")
       return
   ```

6. **Send welcome event** (D-01 format):
   ```python
   await websocket.send_json({
       "event": "connected",
       "agent_id": client_id,  # D-01: same format as agent endpoint
       "timestamp": datetime.now(timezone.utc).isoformat(),
       "data": {"role": payload.get("role", "unknown")}
   })
   ```

7. **Main message loop** - listen for client messages:
   - Handle ping/pong: `{"type": "ping"}` -> respond with `{"event": "pong"}`
   - Handle token refresh: `{"type": "refresh_token", "token": "..."}` -> verify new token, update expiry in ConnectionManager via `cm._ui_expiry[client_id] = new_payload["exp"]`
   - On WebSocketDisconnect: break
   - On other exceptions: log warning, break

8. **Cleanup in finally block**: `await cm.disconnect_ui(client_id)`, log "ws_ui_disconnected"

Log structured events: "ws_ui_auth_started", "ws_ui_connected", "ws_ui_auth_failed", "ws_ui_disconnected" with client_id.
