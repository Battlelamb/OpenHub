## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.1.x (Vite-native) + @testing-library/react 16.x + jsdom 29.x |
| **Config file** | `web/vitest.config.ts` (shares `vite.config.ts` via `mergeConfig`) — Wave 0 creates |
| **Quick run command** | `cd web && npm run test -- --run` (non-watch, fast) |
| **Full suite command** | `cd web && npm run test -- --run && npm run typecheck && npm run lint` |
| **Mock backend** | `msw` 2.x with handlers in `web/src/mocks/handlers.ts` — Wave 0 creates |
| **Backend smoke** | `python -m pytest tests/unit/test_static_mount.py -v` for the FastAPI `/dashboard` mount |
| **Estimated runtime** | ~15s for `npm run test -- --run`, ~30s for full suite |

Backend Python tests (137 passing baseline from Phase 3) remain unchanged. Phase 4 only adds a 5-line `StaticFiles(directory="web/dist", ...)` mount in `app/main.py` plus a single smoke test.

---

## Sampling Rate

- **After every task commit:** Run `cd web && npm run test -- --run` (or backend pytest if the task touches Python)
- **After every plan wave:** Run full suite — `npm run test -- --run && npm run typecheck && npm run lint` plus backend `python -m pytest tests/ -m "not turso" --no-cov`
- **Before `/gsd:verify-work`:** Full suite must be green (frontend + backend)
- **Max feedback latency:** ~30 seconds per task

## Wave 0 Requirements

Wave 0 is a single bootstrap plan (Plan 04-01) that scaffolds the entire `web/` directory before any feature plan can run. After Wave 0:

- [ ] `web/package.json` — Vite 8.x + React 19 + TypeScript 5.x dependencies declared
- [ ] `web/vite.config.ts` — `@tailwindcss/vite` plugin, `@tanstack/router-plugin` plugin, dev server proxy `/v1/*` → `localhost:7788` (HTTP + WS), `base: '/dashboard/'`
- [ ] `web/vitest.config.ts` — Vitest config sharing Vite config via `mergeConfig`
- [ ] `web/tsconfig.json` + `tsconfig.app.json` — strict mode, path alias `@/*` → `src/*`
- [ ] `web/src/main.tsx`, `web/src/App.tsx`, `web/src/index.css` (with `@import "tailwindcss"` + `@theme`)
- [ ] `web/src/lib/cn.ts` (shadcn `cn` utility)
- [ ] `web/components.json` (shadcn config — `cssVariables: true`, `style: "default"`, `tailwind.cssVariables: true`)
- [ ] `web/src/mocks/handlers.ts` + `web/src/mocks/server.ts` (msw setup)
- [ ] `web/src/test/setup.ts` (Vitest globals + msw start/stop hooks)
- [ ] First Vitest sanity test passes: `cn.test.ts` checks `cn('a', 'b') === 'a b'`
- [ ] First TypeScript build passes: `tsc --noEmit` clean
- [ ] First Vite build passes: `npm run build` produces `web/dist/index.html`

Without all these, no Wave 1+ plan can begin.
