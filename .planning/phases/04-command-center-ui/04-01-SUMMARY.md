## Known Issues & Resolutions

### Issue 1: TanStack Router API Change
**Problem:** Planned `createFileRoute('/')` API not compatible with installed 1.168.19.  
**Resolution:** Used `createRoute({ getParentRoute: () => rootRoute, path: '/', ... })` pattern instead.  
**Impact:** Minimal — downstream plans use same pattern.

### Issue 2: Tailwind v4 Plugin Syntax
**Problem:** `@import "tailwindcss-animate"` failed to resolve.  
**Resolution:** Changed to `@plugin "tailwindcss-animate"` (Tailwind v4 syntax).  
**Impact:** None — plugin works identically.
