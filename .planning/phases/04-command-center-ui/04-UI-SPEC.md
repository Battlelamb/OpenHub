# Phase 4 - UI Design Contract

> Visual and interaction contract for the OpenHub Command Center SPA. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Implements UI-01 through UI-16 from REQUIREMENTS.md.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (copy-paste, no runtime lock-in) |
| Preset | manual init (no public preset; project tokens declared below) |
| Component library | Radix UI primitives via shadcn/ui |
| Icon library | lucide-react (ships with shadcn) |
| Font | Inter Variable (self-hosted via `@fontsource-variable/inter`) |
| Styling | Tailwind CSS, `dark:` variant, `class` strategy on `<html>` |
| Base palette | zinc (neutral surfaces) |
| Accent | emerald (success + brand) |
| Default theme | dark (D-02) |

References: D-01 (shadcn + Tailwind), D-02 (dark default + manual light toggle), D-03 (zinc base + emerald accent).

## Spacing Scale

Tailwind defaults, 4px base unit. No custom scale; planner and executor use stock Tailwind classes only.

| Token | Value | Usage |
|-------|-------|-------|
| 1 | 4px | Icon-to-label gap, inline padding inside badges |
| 2 | 8px | Compact data table row vertical padding (data density) |
| 3 | 12px | Data table cell horizontal gap (data density) |
| 4 | 16px | Default form field gap, card content padding |
| 6 | 24px | Section padding inside panels |
| 8 | 32px | Layout gaps between panels |
| 12 | 48px | Major section breaks on detail pages |
| 16 | 64px | Page-level top padding on auth screens |

Layout chrome (locked):
- Sidebar expanded: **256px** (`w-64`)
- Sidebar collapsed: **56px** (`w-14`) - icon-only rail
- Topbar height: **56px** (`h-14`)
- Mobile breakpoint: **md = 768px** (Tailwind default) - below md the sidebar becomes a `Sheet` drawer and tables collapse to card grids (UI-15)
- Data table row vertical padding: **8px** (compact density)
- Data table cell horizontal gap: **12px**

Exceptions: touch targets on mobile (UI-15) follow shadcn Button `size="icon"` minimum 36px; topbar icon buttons stay 36px regardless of breakpoint.

## Typography

Single typeface (Inter Variable). Three weights, four sizes. No custom font stacks.

| Role | Size | Weight | Line Height | Tailwind |
|------|------|--------|-------------|----------|
| Caption | 12px | 500 (medium) | 1.4 | `text-xs font-medium` |
| Body | 14px | 400 (regular) | 1.5 | `text-sm` |
| Section heading | 18px | 600 (semibold) | 1.3 | `text-lg font-semibold` |
| Page title | 24px | 600 (semibold) | 1.2 | `text-2xl font-semibold` |

Tabular figures: enable `font-variant-numeric: tabular-nums` on all numeric columns in data tables and on duration badges in the trace viewer (UI-12).

Monospace: `ui-monospace, "JetBrains Mono", "Fira Code", monospace` for JSON inspectors (UI-12, UI-13), trace IDs, agent IDs, task IDs, and token-expiring countdowns.

## Color

60/30/10 split. All values are Tailwind zinc/emerald/red/amber/sky/violet shades so executor uses class names, not hex.

### Dark theme (default - D-02)

| Role | Value | Usage |
|------|-------|-------|
| Dominant 60% | `zinc-950` (#09090b) | Page background, app shell |
| Secondary 30% | `zinc-900` (#18181b) | Sidebar, topbar, cards, dialogs, popovers |
| Surface elevation | `zinc-800` (#27272a) | Hover state, table row hover, inputs |
| Border | `zinc-800` / `zinc-700` | Card borders, table dividers, input borders |
| Text primary | `zinc-50` (#fafafa) | Body, headings |
| Text secondary | `zinc-400` (#a1a1aa) | Captions, timestamps, helper text |
| Accent 10% | `emerald-500` (#10b981) | Primary CTA, brand mark, focus ring, active sidebar item, success status |
| Destructive | `red-500` (#ef4444) | Cancel task button, retry-on-failure, error toasts, failed status |

### Light theme (manual toggle)

| Role | Value | Usage |
|------|-------|-------|
| Dominant 60% | `zinc-50` (#fafafa) | Page background |
| Secondary 30% | `white` / `zinc-100` | Sidebar, cards, dialogs |
| Surface elevation | `zinc-200` | Hover state |
| Border | `zinc-200` / `zinc-300` | Card borders, dividers |
| Text primary | `zinc-950` | Body, headings |
| Text secondary | `zinc-500` | Captions, helper text |
| Accent 10% | `emerald-600` | Primary CTA, brand mark, focus ring (darker for AA contrast on light) |
| Destructive | `red-600` | Same role as dark theme |

### Accent reserved for (explicit list - never "all interactive elements")

emerald-500/600 is allowed ONLY on:
1. Primary CTA buttons (`<Button variant="default">`) - one per dialog/page max
2. Brand wordmark in the topbar
3. Focus ring on keyboard-focused interactive elements
4. Active sidebar nav item (left rail accent stripe + icon color)
5. Agent online status dot + agent online badge label
6. Task `completed` status badge + checkmark icon
7. Toast `success` variant left border + icon
8. Health indicator dot when `/v1/health` returns OK (UI-08)

Everything else uses zinc neutrals. No emerald on links, table headers, secondary buttons, sidebar inactive items, tab bars, or breadcrumbs.

### Status color map (locked)

**Agent status (UI-02, UI-07):**

| Status | Dot | Badge background | Badge text |
|--------|-----|------------------|------------|
| online | `emerald-500` | `emerald-500/10` | `emerald-400` |
| idle | `amber-500` | `amber-500/10` | `amber-400` |
| offline | `zinc-500` | `zinc-500/10` | `zinc-400` |
| error | `red-500` | `red-500/10` | `red-400` |

**Task status (UI-03, UI-05, UI-10):**

| Status | Color | Treatment |
|--------|-------|-----------|
| queued | `zinc-400` | Static dot |
| claimed | `violet-400` | Static dot |
| running | `sky-400` | Pulsing dot (`animate-pulse`) |
| completed | `emerald-500` | Static dot + checkmark icon |
| failed | `red-500` | Static dot + alert icon |
| cancelled | `zinc-500` | Static dot + strikethrough on task title |

**Toast variants (UI-09):**

| Variant | Color | Trigger |
|---------|-------|---------|
| success | `emerald-500` left border + icon | 2xx mutations |
| info | `sky-500` left border + icon | Informational events (e.g. token refreshed silently) |
| warning | `amber-500` left border + icon | 4xx responses, `token_expiring` event (D-15) |
| error | `red-500` left border + icon | 5xx responses, network failures, RFC 7807 problem detail with `status >= 500` |

Toast body renders `title` + `detail` from the RFC 7807 `ProblemDetail` shape exposed by `app/models/errors.py`.

## Layout & Interaction Patterns

### App shell (locked - covers UI-01..UI-16)

```
+----------------------------------------------------------+
| Topbar 56px: brand | reconnecting banner | health | user |
+--------+-------------------------------------------------+
| Side   |                                                 |
| 256px  |               Page content                      |
| (col-  |                                                 |
| lapses |                                                 |
| to     |                                                 |
| 56px   |                                                 |
| icon   |                                                 |
| rail)  |                                                 |
+--------+-------------------------------------------------+
```

Sidebar groups (D-12):
1. **Operations** - Agents (UI-02, UI-07), Tasks (UI-03, UI-04, UI-05), Workflows (UI-06)
2. **Visibility** - DLQ (UI-10), Costs (UI-11), Traces (UI-12), Memory (UI-13), Locks (UI-14)
3. **Admin** - Health (UI-08 detail page), Settings (theme, language, sign out)

Each sidebar item: lucide icon (20px) + label, 36px row height, active state = emerald accent stripe on left edge + emerald icon + zinc-50 label, hover = zinc-800 background.

### Data table density

shadcn `Table` (Radix-free, plain HTML table) with TanStack Table for sorting/filtering. Compact density:
- Row vertical padding: 8px (`py-2`)
- Cell horizontal gap / padding: 12px (`px-3`)
- Header: 12px caption text, uppercase, `text-zinc-400`, sticky on scroll
- Row hover: `hover:bg-zinc-800/50`
- Selected row: `bg-zinc-800`
- Row dividers: 1px `border-zinc-800`

### Mobile responsive (UI-15)

Below `md` (768px):
- Sidebar becomes a `Sheet` drawer triggered by topbar hamburger icon
- Tables collapse to a vertical card stack: each row becomes a `Card` with key fields stacked label-above-value, primary action as a full-width button at the bottom of the card
- Topbar collapses brand to icon only, hides reconnecting banner text (keeps icon), keeps health dot and user menu

### Trace viewer (UI-12) - locked spec

Vertical timeline, custom render (no library, per D-discretion + specifics):
- Root span at the top, each child indented **2 levels** (16px per level via `pl-4`)
- Maximum visible nesting depth before horizontal scroll: 6 levels
- Each node row contains: expand chevron (16px) | category icon (16px) | span name (body 14px) | proportional duration bar (right-aligned, fills remaining width) | duration badge (tabular-nums, 12px caption)
- **Color-coded by category** (left edge of each node, 3px stripe):
  - `llm` / model call: `violet-400`
  - `tool` call: `sky-400`
  - `db` / storage: `amber-400`
  - `http` / external API: `emerald-400`
  - `internal` / sub-step: `zinc-500`
  - `error` span: `red-500`
- **Proportional duration bar:** width = `(span.duration / root.duration) * available_width`, background = category color at 20% opacity, foreground = category color at 60% opacity
- **Click to expand:** Clicking any node row opens a side panel `Sheet` containing a JSON inspector (monospace, 12px caption, syntax-highlighted via `react-json-view-lite` or equivalent lightweight viewer - planner picks). The inspector shows full span attributes, events, and metadata.
- Empty state: see copy table above

### Memory viewer (UI-13)

Compact data table: columns = Key (mono) | Size (tabular-nums, KB/MB) | Age (relative time, e.g. "3m ago") | Actions (eye icon to open JSON inspector). Click eye icon opens shadcn `Sheet` with monospace JSON inspector identical to trace viewer's inspector pattern.

### Toast positioning (UI-09)

Top-right on desktop, top-center on mobile. Stack vertically, max 3 visible, auto-dismiss 5s for success/info, 8s for warning, sticky for error (manual dismiss). Library: `sonner` (recommended; planner may override per D-discretion).
